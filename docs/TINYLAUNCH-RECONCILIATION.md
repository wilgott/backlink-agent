## Operating rule

1. Use the overlap table to avoid paying TinyLaunch to resubmit sites already tracked here.
2. Qualify new candidates independently: free listing path, relevant audience, public listing URL, and backlink/link-type evidence.
3. Only then promote a candidate into `data/directory-database.csv` and regenerate `data/qualified-sites.json` with `python scripts/build-data-json.py`.

The JSON snapshot is suitable for importing into a separate Notion database if a Notion connector is added later; until then, this repo remains the versioned source of truth.
